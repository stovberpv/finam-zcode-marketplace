# Routine icon

Three cards represent Atlassian (blue), GitLab (orange), and AI (violet). Violet is a design choice for AI, not an official AI brand color. Created with built-in imagegen. Previous concepts are not distributed.

The final edit preserves the three-card shape and uses blue #1868DB, orange #FC6D26 and violet #8B5CF6 as palette references on an off-white background.
