Контекст пользователя: $ARGUMENTS

Прочитай `.harness/workflow/project.yaml` и указанный в `review.executor.source` проектный документ. Определи проверяемые изменения и версии по текущей работе; уточни только неоднозначное. Выполни проектное ревью согласно выбранному способу вызова. Верни результат в текущий разговор по формату `workflow-review-v1`, переданному общим скиллом или доступному в ресурсах установленного плагина.

Не исправляй код, не выполняй commit / push и не публикуй замечания самостоятельно. Общий скилл сопровождения оформит и опубликует результат по поручению.

Этот файл — заготовка ручной команды. Инициализатор адаптирует её к реальному исполнителю проекта. Не настраивать executor.source на эту же обёртку: он должен вести к содержательной инструкции ревью, иначе получится рекурсивный вызов.
