# Каталог шаблонов

Файлы — ресурсы плагина, не обязательные копии в каждом репозитории. Подставляй установленные факты, не публикуй незаполненные плейсхолдеры. Неприменимое обозначай с причиной. Существенное существующее содержимое сохраняй при приведении к формату.

| Когда нужен | Шаблон |
|---|---|
| Инициализация YAML | [project.yaml](project.yaml) |
| Пример структуры, не готовые настройки | [project.example.yaml](project.example.yaml) |
| Новый индекс документации | [index.md](index.md) |
| Создание / структурирование правил | [ruleset.md](ruleset.md) |
| Согласованная проектная инструкция ревью | [review.md](review.md) |
| Необязательная ручная команда ZCode | [routine_review.command.md](routine_review.command.md) |
| Итог инициализации | [initialization.md](initialization.md) |
| Задача / подзадача Jira | [jira-task.md](jira-task.md) |
| Итог работы в Jira | [jira-comment.md](jira-comment.md) |
| Описание MR | [mr-description.md](mr-description.md) |
| Замечание / ответ в GitLab | [gitlab-thread.md](gitlab-thread.md) |
| Результат проектного ревью | [review-result.md](review-result.md) |
| Результаты проверок | [quality-report.md](quality-report.md) |
