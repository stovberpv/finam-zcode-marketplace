# Finam Engineering

Плагины, которые превращают ИИ-агентов в инструменты вашей команды. Готовые команды, интеграции и рабочие подходы для повседневных задач — от разработки и анализа до документации и автоматизации. Выбирайте нужные возможности и подключайте их к своему проекту.

## Routine · 0.2.0 alpha

<img src="plugins/routine/assets/icon.png" width="128" alt="Routine">

Вы занимаетесь разработкой — Routine помогает оформить результат. Создаёт и обновляет задачи Jira, готовит описания merge request, запускает проектное ревью и оформляет его результаты по стандартам команды. Начать можно в любой момент: с идеи, существующей задачи или уже написанного кода. Routine собирает контекст проекта и уточняет недостающее, чтобы вам не приходилось каждый раз заново объяснять процесс и переносить данные вручную.

**[Установка и примеры команд для коллег](docs/quickstart.md)**

В ZCode: **Settings → Plugins → Create → Add marketplace** → `https://github.com/stovberpv/finam-zcode-marketplace.git` → **Personal → finam → routine → Install**.

- `/routine_setup` — исследовать проект и согласовать настройки, правила и исполнителя ревью.
- `/routine` — оформить Jira/MR, вызвать проектное ревью и оформить его результат.

[Требования и устройство плагина](plugins/routine/README.md) · [Контракт проекта](plugins/routine/references/project-contract.md) · [Шаблоны](plugins/routine/templates/README.md)

Настройки проекта: `.harness/routine/project.yaml`. Код, коммиты и push остаются у проектных инструментов. Для Jira нужны официальный Atlassian MCP и TWG, для GitLab — настроенный glab. Плагин не устанавливает эти зависимости.

## Разработка

```sh
python3 scripts/build_plugin.py
python3 -m unittest discover -s tests -v
```

Тесты разработки требуют PyYAML; сборка использует стандартную библиотеку Python. Архив для локальной установки создаётся в `dist/`.

При обновлении менять version в `marketplace.json` и `.zcode-plugin/plugin.json` вместе. Затем в ZCode обновить источник marketplace и проверить обновления плагина.

Структурные проверки выполнены. Реальная установка и работа интеграций в конкретной версии ZCode должны быть проверены на пилоте.

Технический ID marketplace — `finam`. ZCode требует строчное имя без пробелов и пока не поддерживает отдельное отображаемое название каталога. Бренд каталога — **Finam Engineering**.
