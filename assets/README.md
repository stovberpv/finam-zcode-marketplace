# Finam

`finam-logo.svg` — оригинальный знак Финам, скачанный без изменений из официальной документации Finam Trade API.

Источник: https://api.finam.ru/api/icons/file/Finam%20logo%20flame.svg/

Страница: https://api.finam.ru/docs/rest

Файл используется для оформления репозитория. Отдельное поле логотипа marketplace в документации ZCode не подтверждено; выдуманное поле в manifest не добавляется. Иконка плагина подключена через поддерживаемое поле `plugins[].icon`.
